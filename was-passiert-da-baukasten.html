Aktiv vs. Passiv — der Fokus-Shift

Derselbe Vorgang, zwei Perspektiven.

👤➡️📝
AKTIV
„Anna schreibt einen Brief."
Wann? Wenn die handelnde Person wichtig ist und wir betonen wollen, WER etwas tut.
📝✨
PASSIV
„Ein Brief wird geschrieben."
Wann? Wenn die HANDLUNG wichtig ist — wer es macht, ist egal oder unbekannt.
Die goldene Formel
WERDEN + Partizip II = PASSIV
„wird gebaut · wird gekocht · wird repariert · werden gespült"

3 Polaroids — Schnappschüsse aus dem Alltag

So einfach kann eine Beschreibung sein!

🏗️ Baustelle
„Hier wird ein Haus gebaut."
🍲 Küche
„Die Suppe wird gerade gekocht."
💇 Friseursalon
„Die Haare werden geschnitten."
💡 Der Trick: Passiv ist KEINE Verb-Liste zum Auswendiglernen. Es ist eine Perspektive! Frag dich: „Will ich erzählen, was passiert, oder wer es macht?"

Redemittel für die Bildbeschreibung

Diese Sätze brauchst du IMMER — auch in der DSH/TestDaF-Prüfung!

Einstieg
„Auf diesem Bild sieht man…"
Räumlich
„Auf der linken Seite WIRD…"
Aktion läuft
„Es WIRD GERADE… (gekocht/gebaut/repariert)."
Vordergrund
„Im Vordergrund STEHT eine Person, die…"
Hintergrund
„Im Hintergrund SIEHT MAN, wie…"
Gleichzeitigkeit (B2)
„Während im Vordergrund X gemacht WIRD, WIRD im Hintergrund Y…"
Vermutung (B2)
„Anscheinend WIRD hier… / Es macht den Eindruck, dass…"
Zusammenfassung
„Was hier passiert, ist…"

Quiz: Welcher Passiv-Satz?

Aktiv-Satz lesen — den passenden Passiv-Satz wählen.

Aktiv: „Die Putzfrau reinigt die Räume." — Passiv?
Die Räume werden gereinigt.Die Putzfrau wird gereinigt.Die Räume werden geputzt.
✓ Akkusativ-Objekt (die Räume) wird zum Subjekt. Hilfsverb: werden. Partizip: gereinigt.
„Bauarbeiter bauen ein neues Haus." — Passiv?
Bauarbeiter wird gebaut.Ein Haus baut.Ein neues Haus wird gebaut.
✓ „werden + gebaut" — Akkusativ-Objekt → Subjekt
„Im Restaurant ___ jeden Tag frisches Brot ___." (B1)
ist / gebackenwird / gebackenhat / gebacken
✓ Passiv = werden + Partizip II
„In dieser Bibliothek ___ leise gesprochen." (subjektloses Passiv)
wirdwerdenist
✓ „Es wird leise gesprochen" — subjektloses Passiv (allgemein, ohne Akteur)
„Beim Friseur ___ den Kunden die Haare ___." (Bekommen-Passiv-Alternative)
sind / schneidenwerden / schneidenwerden / geschnitten
✓ „den Kunden" (Dativ!) werden die Haare geschnitten — Dativ-Passiv
„Auf der Baustelle ___ schwere Steine ___." (Plural-Objekt!)
wird / getragenwerden / getragenwerden / tragen
✓ Plural-Subjekt = „werden" (3.Pl) + Partizip II!
„Im Stadion ___ heute Abend ___." (subjektloses Passiv · Sport)
wird / gespieltist / gespieltwerden / spielen
✓ „Es wird gespielt" — allgemein, kein konkretes Objekt
„Anscheinend ___ hier seit Stunden ___." (B2 Vermutung + Reparatur)
ist / repariertwird / repariertwürde / reparieren
✓ Passiv Präsens: wird repariert. „Anscheinend" = Vermutung-Adverb!

Lückentext · Aktiv → Passiv

Schreibe den Passiv-Satz in die Lücke. (Form: wird/werden + Partizip II)

1. Aktiv: „Der Lehrer erklärt die Grammatik." → Passiv: Die Grammatik .
2. Aktiv: „Die Bauarbeiter bauen ein Haus." → Passiv: Ein Haus .
3. Aktiv: „Wir kochen die Suppe." → Passiv: Die Suppe .
4. Aktiv: „Die Kellnerin serviert die Getränke." → Passiv: Die Getränke .
5. Aktiv: „Die Schüler lernen Vokabeln." → Passiv: Vokabeln .
6. Aktiv: „Der Friseur schneidet die Haare." → Passiv: Die Haare .
7. Aktiv: „Mein Vater repariert das Auto." → Passiv: Das Auto .

🖼️ 8 Bilder zum Beschreiben

Schau dir die Szene an — beschreibe IM PASSIV, was passiert! Tippe auf „Musterlösung" wenn du fertig bist.

1
🏗️ Auf der Baustelle
Aufgabe: Beschreibe mit MINDESTENS 5 Passiv-Sätzen, was hier passiert.
bauentragenstreichenarbeitender Krandie Mauerdie Steine
Auf diesem Bild sieht man eine Baustelle. Im Vordergrund wird ein Haus gebaut. Steine werden von einem Kran transportiert. Im Hintergrund wird eine Mauer gestrichen. Zwei Arbeiter sind zu sehen — sie tragen Helme. Insgesamt wird hier hart gearbeitet!
2
🍲 In der Küche
Aufgabe: 5+ Passiv-Sätze: Was wird hier alles gleichzeitig gemacht?
kochenbratenschneidenvorbereitender Herdder Ofendas Gemüse
Hier wird ein Festessen vorbereitet. Auf dem Herd wird eine Suppe gekocht. Im Ofen wird ein Hähnchen gebraten. Auf dem Tisch werden Gemüse, Salat und Tomaten geschnitten. Der Koch ist sehr beschäftigt — alles muss schnell gemacht werden!
3
💇 Im Friseursalon
Aufgabe: 5+ Passiv-Sätze + 1 BEKOMMEN-Passiv („Die Kundin bekommt die Haare geschnitten")!
schneidenwaschenfärbenfönenbezahlender Spiegeldie Kasse
Im Friseursalon werden viele Dinge gleichzeitig gemacht. Eine Kundin bekommt die Haare geschnitten (Bekommen-Passiv!). Einer anderen werden die Haare gewaschen. Im Hintergrund wird jemandem eine Tönung aufgetragen. An der Kasse wird bezahlt. Es wird viel geplaudert!
4
☕ Im Café
Aufgabe: 5+ Passiv-Sätze über das Café-Leben — Vordergrund vs. Hintergrund!
servierenbestellentrinkenplaudernbezahlender Kellnerder Kuchen
Im Café wird sonntags viel geplaudert. An einem Tisch werden Kaffee und Croissants serviert. Am anderen Tisch wird auf dem Handy gelesen. Im Hintergrund an der Theke wird frischer Kaffee gemacht. Es wird ständig bestellt und bezahlt — das Café ist voll!
5
🚉 Im Bahnhof
Aufgabe: 6+ Passiv-Sätze über Bahnhof-Aktivitäten + 1 Verspätungs-Satz!
einsteigenaussteigenwartenkontrollierendurchsagender Schaffnerder Koffer
Auf dem Bahnhof wird gerade ein ICE angesagt. Im Vordergrund werden Tickets kontrolliert. Koffer werden in den Zug gebracht. Auf der Anzeigetafel wird die Abfahrtszeit angezeigt. Es wird auch viel gewartet. Und es wird durchgesagt, dass der Zug 5 Minuten Verspätung hat.
6
💼 Im Büro
Aufgabe: 5+ Passiv-Sätze über typische Büroaktivitäten!
schreibentelefonierendruckenbesprechenkopierender Computerdie E-Mail
Im Büro wird heute viel gearbeitet. An den Computern werden E-Mails beantwortet. Berichte werden gerade geschrieben. Am Drucker werden Dokumente gedruckt. Im Hintergrund wird telefonisch über ein Projekt diskutiert. Es wird nicht viel gelacht — Montagmorgen ist intensiv!
7
🌳 Im Park
Aufgabe: 5+ Passiv-Sätze über Freizeit-Aktivitäten im Park!
spielenspazierenlesenlaufenfütternder Hundder Ball
Im Park wird sonntags viel gemacht. Auf der Bank wird ein Buch gelesen. Im Vordergrund wird mit einem Ball gespielt. Ein Hund wird gerade ausgeführt. Auf den Wegen wird spaziert. Es wird die Sonne genossen — die Stadt ist hier ganz weit weg!
8
🛒 Im Supermarkt
Aufgabe: 6+ Passiv-Sätze über Einkaufen, Bezahlen, Bedienen!
einkaufenbezahlenscanneneinpackenverkaufendie Kasseder Einkaufswagen
Im Supermarkt wird samstags viel eingekauft. In den Regalen werden Lebensmittel angeboten. Im Vordergrund wird ein Einkaufswagen geschoben. An der Kasse werden Produkte gescannt und bezahlt. Es wird auch viel gefragt — wo etwas verkauft wird. Total stressig am Wochenende!

3 Rollenspiele live

Übt zu zweit — beschreibt Situationen im Passiv!

Rollenspiel 1 · Reporter
📺 Telefonische Bildbeschreibung
Person A beschreibt am Telefon ein Bild — Person B zeichnet nur basierend auf der Beschreibung. Am Ende vergleichen!
🎙️
Person A — Reporter
„Im Vordergrund wird ein Haus gebaut. Links wird eine Mauer gestrichen…"
✏️
Person B — Zeichner
„Ist das eine große oder kleine Mauer? Wird die gestrichen oder gebaut?"
🎯 Ziel: Mindestens 10 Passiv-Sätze pro Beschreibung!
Rollenspiel 2 · Live-TV
📡 Reporter vor Ort — Live-Event
Szenario: Live-Event (Konzert, Demo, Hochzeit, Sportfest). A ist Reporter vor Ort, B sitzt im Studio und stellt Fragen.
🎤
Person A — vor Ort
„Hier wird gerade gefeiert! Auf der Bühne wird ein Lied gesungen. Im Publikum wird getanzt!"
🎬
Person B — im Studio
„Was wird dort sonst noch gemacht? Wird etwas verkauft? Wer ist da?"
🎯 Ziel: 10 Passiv-Sätze + mindestens 3 mit „wird gerade"!
Rollenspiel 3 · Kettenreaktion
🎮 Das große Passiv-Sprechspiel
Gruppenspiel! Jede:r baut auf dem vorherigen Satz auf — und WIEDERHOLT alles Vorherige. Wer einen Fehler macht, scheidet aus.
1️⃣
Runde 1
„In der Schule wird gelernt."
2️⃣
Runde 2
„In der Schule wird gelernt UND es werden Pausen gemacht."

4 Thesen zum Debattieren

4 Gruppen — jede verteidigt eine These mit Passiv-Argumenten.

These 1
„Bildbeschreibungen sind die beste Methode, um eine Fremdsprache zu lernen."
These 2
„In Deutschland wird zu viel im Passiv geschrieben — die Texte werden dadurch langweilig."
These 3
„Reporter sollten immer im Passiv berichten — das wirkt objektiver und professioneller."
These 4
„Bilder sagen mehr als 1000 Worte — Sprachunterricht braucht keine Texte mehr."
🎯 Pflicht: In jeder Argumentation mindestens 5 Passiv-Sätze verwenden — denke auch an Vermutungen („Es wird angenommen, dass…") und allgemeine Aussagen („Hier wird oft diskutiert…")!
