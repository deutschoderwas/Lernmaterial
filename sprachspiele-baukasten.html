Die goldenen Sprechclub-Regeln
  1. Nur Deutsch sprechen! Auch beim Lachen 😄
  2. Mut zur Lücke — falsche Sätze sind besser als Schweigen!
  3. Korrigiert euch gegenseitig — aber LIEBEVOLL

🎲 Spiel 1: Themen-Rad

Dreht das Rad — sprecht 90 Sekunden über das Thema mit dem PFLICHT-Detail!

🎯 So spielt ihr:

  1. Spieler A drückt „Drehen"
  2. Das Rad zeigt ein Thema + eine GRAMMATIK-Pflicht
  3. Spieler A spricht 90 Sekunden über das Thema
  4. Mindestens 5 Sätze müssen die Pflicht-Grammatik enthalten!
  5. Andere Spieler hören zu und zählen die Pflicht-Sätze
  6. 5+ richtig = 1 Punkt 🏆
Bereit?
Drücke „Rad drehen"!

🎤 Spiel 2: Tabu

Erkläre das Wort — OHNE die 5 Tabu-Wörter zu benutzen!

🎯 So spielt ihr:

  1. Spieler A bekommt ein Wort + 5 verbotene Tabu-Wörter
  2. A hat 60 Sekunden Zeit, das Wort zu erklären — OHNE die Tabu-Wörter
  3. Die anderen müssen das Wort raten
  4. Erraten = 2 Punkte für A + 1 Punkt für den Errater
  5. Tabu-Wort gesagt = MINUS 1 Punkt für A 😬
Neues Tabu-Wort?
Drücke unten!

⏱️ Spiel 3: 60-Sekunden-Challenge

Schaffe es, 60 Sekunden ohne „äh" und ohne Pause über ein Thema zu sprechen!

🎯 So spielt ihr:

  1. Spieler A bekommt ein Thema
  2. A spricht 60 Sekunden ohne Pause + ohne „äh"
  3. „Äh", „hmm", lange Pausen = Ausgeschieden 😱
  4. Schafft A 60 Sek = 3 Punkte!
  5. Andere können „STOP!" rufen wenn sie ein „äh" hören
Bereit zum Sprechen?
Tippe für neues Thema!

🃏 Spiel 4: Story-Karten

5 Zufallswörter → eine zusammenhängende Geschichte erfinden!

🎯 So spielt ihr:

  1. Drücke „5 Karten ziehen"
  2. Du bekommst 5 zufällige Wörter aus den Wochenthemen
  3. Erzähle eine ZUSAMMENHÄNGENDE Geschichte mit ALLEN 5 Wörtern
  4. Mindestens 8 Sätze!
  5. Bonus: 1 Konjunktiv-II-Satz + 1 Passiv-Satz = +2 Punkte!
Deine 5 Story-Wörter
Klick zum Ziehen!

🔄 Spiel 5: Kettenreaktion

Jeder Satz beginnt mit dem letzten Wort des vorherigen!

🎯 So spielt ihr:

  1. Spieler A bekommt ein Startwort (Klick unten!)
  2. A bildet einen Satz mit dem Wort am Anfang
  3. Spieler B muss einen Satz mit dem LETZTEN Wort von A's Satz beginnen
  4. Spieler C macht weiter mit dem letzten Wort von B
  5. Wer keinen Satz bildet → scheidet aus
  6. Beispiel: „Apfel ist gesund. Gesund sein macht glücklich. Glücklich werden alle bei der Hochzeit."
Startwort
Klick zum Start!

🎯 Spiel 6: Frage-Sturm

Eine provokante Frage — beide Spieler antworten je 90 Sekunden, dann diskutieren!

🎯 So spielt ihr:

  1. Klick auf „Provokante Frage"
  2. Spieler A antwortet 90 Sekunden — gibt seine Position
  3. Spieler B antwortet 90 Sekunden — gibt SEINE Position
  4. Dann: 2 Minuten Diskussion!
  5. Pflicht: mindestens 3 Konnektoren („weil", „obwohl", „trotzdem")
  6. Wer mehr Redemittel nutzt = Sieger 🏆
Nächste Frage?
Drücke unten!

🏆 Spiel 7: Speed-Quiz

Schnelle Fragen aus allen Wochenthemen — Punkte sammeln!

🎯 So spielt ihr:

  1. Klick „Frage" — du bekommst eine Frage aus den Wochenthemen
  2. Beantworte IMMER in einem KOMPLETTEN deutschen Satz
  3. Richtig = 1 Punkt
  4. Spielt 10 Runden gegeneinander
  5. Wer am Ende mehr Punkte hat = Champion! 🏆
Bereit?
Drücke „Nächste Frage"!
