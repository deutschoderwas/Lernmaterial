Das Passiv

Das Auto wird repariert. Das Paket wurde geliefert. Hier darf nicht geparkt werden. Endlich klar — wann Passiv kommt und wie alle Zeiten funktionieren!

Aktiv vs. Passiv

Im Aktiv ist wichtig, WER etwas macht. Im Passiv ist wichtig, WAS passiert.

💡 Der Trick: Passiv = werden + Partizip 2 am Ende. Das, was im Aktiv das Objekt (Akkusativ) war, wird im Passiv zum Subjekt. Beispiel: „Der Mechaniker repariert das Auto." → „Das Auto wird (vom Mechaniker) repariert." Der Macher (Mechaniker) ist oft unwichtig oder unbekannt!
🚗 Aktiv → Passiv: Beispiel
AKTIV
„Der Mechaniker repariert das Auto."
WER macht es? = wichtig
→
PASSIV
„Das Auto wird repariert."
WAS passiert? = wichtig

Die Passiv-Tabelle

Alle Zeiten auf einen Blick — Beispiel mit „reparieren".

📋 Passiv — alle Zeitformen

ZeitFormelBeispiel
Präsenswird + P2Das Auto wird repariert.
Präteritumwurde + P2Das Auto wurde repariert.
Perfektist + P2 + wordenDas Auto ist repariert worden.
Plusquamperf.war + P2 + wordenDas Auto war repariert worden.
Modalverbkann/muss/darf + P2 + werdenDas Auto muss repariert werden.
Zustandspassivist + P2 (sein!)Das Auto ist repariert. (Ergebnis!)
🎯 Die 3 Stolperfallen:
1. Perfekt = „worden" (nicht „geworden"!) → „Das Paket ist geliefert worden."
2. Modalverb + Passiv: Modal bleibt konjugiert, dann P2 + werden → „Das muss gemacht werden."
3. Vorgangspassiv vs. Zustandspassiv: „wird geschlossen" = passiert gerade vs. „ist geschlossen" = Ergebnis.

Die 6 Passiv-Formen in Aktion

Tipp auf eine Karte 👈 — sieh Bildung + Beispiel.

👇
Form 1 · Präsens
werden + P2
Es passiert gerade / regelmäßig
„Das Paket wird heute geliefert."
„Hier werden Pizzen gebacken."
„Ich werde oft gefragt."
„Du wirst gesucht!"
⏳
Form 2 · Präteritum
wurde + P2
Es ist gestern/früher passiert
„Mein Auto wurde geklaut!"
„Das Haus wurde 1920 gebaut."
„Wir wurden eingeladen."
„Die Tür wurde geschlossen."
✅
Form 3 · Perfekt
ist + P2 + worden
Mündlich oft statt Präteritum
„Das Paket ist geliefert worden."
„Mein Handy ist gestohlen worden!"
„Du bist eingeladen worden?"
⚠️ nicht „geworden" — nur „worden"!
🔐
Form 4 · mit Modalverb
kann/muss/darf + P2 + werden
Möglichkeit / Pflicht / Verbot
„Das muss heute noch gemacht werden."
„Hier darf nicht geraucht werden."
„Das Problem kann gelöst werden."
„Der Test soll wiederholt werden."
🏘
Form 5 · Zustandspassiv
sein + P2 (Ergebnis!)
Zustand nach der Handlung
„Die Tür ist geschlossen." (jetzt geschlossen)
„Das Geschirr ist gespült." (Ergebnis!)
„Der Brief ist geschrieben."
vs. „wird geschrieben" = passiert gerade
🤝
Form 6 · Passiv-Ersatz
man / sich lassen / sein zu
Ohne „werden" das Gleiche sagen!
„Man kann das lösen." (= kann gelöst werden)
„Das lässt sich machen." (= kann gemacht werden)
„Das ist zu sehen." (= kann gesehen werden)
Sehr alltagsnah und natürlich!

Eine Frage zwischendurch

Denk kurz nach — formuliere innerlich einen Passivsatz.

Alltag · Präsens
Was wird bei dir zu Hause gerade gemacht (gekocht, gewaschen, repariert)?
💭 „Bei uns wird gerade … gekocht / gewaschen / …"
Alltag · Präteritum
Wann wurde dein Haus / deine Wohnung gebaut?
💭 „Mein Haus wurde 19.. / 20.. gebaut."
Alltag · Modalverb
Was muss bei dir heute noch gemacht werden?
💭 „Die Wäsche muss noch gewaschen werden / Die Küche muss …"
Alltag · Verbot
Wo darf in deiner Stadt nicht geraucht / geparkt werden?
💭 „In … darf nicht … werden."

💬 So benutzt man Passiv im Alltag

Echte WhatsApp-Chats — Passiv ist überall, besonders bei Nachrichten, Schäden und Bürokratie!

🔥 Tipp: Im Alltag hörst du Passiv besonders oft, wenn jemand etwas Negatives meldet („Mein Handy wurde geklaut!"), eine Lieferung erwähnt („Wird heute geliefert"), oder eine Regel kommuniziert („Hier darf nicht…").

Schadensmeldung! Präteritum (wurde geklaut/informiert) + Zustandspassiv (ist versichert) + Perfekt (ist abgeschlossen worden).

3 Rollenspiele mit Passiv

Übt zu zweit — nutzt möglichst viele Passivformen in allen Zeiten!

Rollenspiel 1 · Pressekonferenz
🎤 „Was wurde gesagt?"
Eine Person ist Pressesprecher:in einer Firma — die andere Person ist Journalist:in. Es gab einen Vorfall (z.B. Datenleck). Erkläre, was passiert ist, was gemacht wird und was noch gemacht werden muss.
🎤
Person A — Pressesprecher:in
„Gestern wurde ein Sicherheitsproblem entdeckt. Die Kundendaten wurden nicht gestohlen. Das Problem kann schnell gelöst werden. Alle Kunden werden informiert."
📝
Person B — Journalist:in
„Wann wurde der Vorfall bemerkt? Was muss jetzt getan werden? Wird die Polizei informiert? Kann garantiert werden, dass das nicht wieder passiert?"
🎯 Ziel: Mindestens 6 verschiedene Passivformen (Präteritum, Präsens, Modal-Passiv)!
Rollenspiel 2 · Schaden melden
🚗 „Mein Auto wurde geklaut!"
Du gehst zur Polizei oder zur Versicherung und meldest einen Schaden (Auto/Handy/Fahrrad gestohlen, Wohnung eingebrochen, Paket verschwunden…). Beschreibe, was passiert ist und was schon gemacht wurde.
😭
Person A — Geschädigte:r
„Mein Fahrrad wurde heute Nacht gestohlen! Das Schloss wurde aufgebrochen. Das Fahrrad war versichert. Die Polizei ist schon informiert worden."
👮
Person B — Beamtin/Beamter
„Wann wurde es bemerkt? Was für ein Schloss wurde benutzt? Ein Protokoll muss ausgefüllt werden. Sie werden dann per Mail informiert."
🎯 Bonus: Mindestens 1× Perfekt Passiv (ist … worden)!
Rollenspiel 3 · Bürokratie erklären
🏢 „So funktioniert der Antrag"
Du arbeitest in einem Bürgeramt und erklärst einer Person, was alles gemacht werden muss, wann etwas bearbeitet wird, was nicht gemacht werden darf etc.
💼
Person A — Beamtin/Beamter
„Der Antrag muss ausgefüllt werden. Geld kann hier nicht bezahlt werden — nur per Überweisung. Der Antrag wird in 4 Wochen bearbeitet."
🧐
Person B — Bürger:in
„Was muss mitgebracht werden? Wann wird der Antrag bearbeitet? Kann er nicht schneller bearbeitet werden? Wie werde ich informiert?"
🏆 Bonus: Wer 8+ verschiedene Passivformen unterbringt, gewinnt!
